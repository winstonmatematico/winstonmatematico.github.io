Tutorial em vídeo: instalando o Apache Hop no Windows

Prof. Dr. Winston Aparecido Andrade

O Apache Hop é uma plataforma gratuita para construir fluxos de dados (pipelines) de forma visual, sem escrever código. Preparei este tutorial para quem está começando: do Java ao primeiro pipeline funcionando, com as telas reais de cada passo. A narração é feita por uma voz sintética, e o conteúdo e as telas são de minha autoria.

Versão completa (cerca de 8 min)

Assistir no YouTube

Instalação do Java 21 e do Apache Hop 2.20.0, com todos os passos na prática.

Versão resumida (cerca de 4 min)

Assistir no YouTube

Os passos essenciais, para quem já conhece o ambiente.

O que você vai ver

  1. Verificação e instalação do Java 21 (JDK) no Windows.
  2. Configuração da variável JAVA_HOME e conferência com java -version.
  3. Download e extração do Apache Hop 2.20.0.
  4. Abertura da interface gráfica (Hop GUI) pelo Prompt de Comando.
  5. Primeiro teste: um pipeline pronto, executado na tela principal.

Requisitos

  • Windows 10 ou 11, com permissão para instalar programas.
  • Conexão com a internet para baixar o Java e o Apache Hop.
  • Cerca de 1 GB de espaço livre em disco.
